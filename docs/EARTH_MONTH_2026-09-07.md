# Earth Month integration

Existing content preserved: calendarProvocations/earth-day-systems, titled Earth Day: Which Change Can We Actually Track?, plus the existing map/power inquiry and all other grade-band lessons.

New entry: a collapsible Earth Month resource strip above the normal hub header. It hides in existing projection and in print. Four routes open an independent local resource at earth-stuff-fairness/: K–2, 3–5, 6–8 and 9–12. The core is six Grade 6 investigations, supported by supplied evidence/story cards, diagrams, optional Story of Stuff films, student print views and teacher notes. Younger grades have shorter object-based materials; older grades have additional source/policy inquiry and the US-specific Citizens United option.

Teacher Hub is the single authoring source. Build-time synchronization uses immutable commit d7bd8c264a417820c3c1a417e1070e885853bd33 and verifies each downloaded file against its Git blob hash. A valid local cache can be reused; an unverified download fails the build. No source is fetched while students use the published page, and the full core works without video or another hub. Change the pin only for a reviewed release.
